🚀 CeXia v1.0.0 — Intelligent AI Task Collaboration Platform

Run your virtual company with 9 specialized AI agents. Define your roadmap, set priorities, and let the agents handle the rest — 24/7.

✨ Key Features:
- 9-agent standard team (PM, Architect, Fullstack, UI/UX, QA, Ops, Marketing, Admin, Sentinel)
- Pluggable task engine — swap backends (SQLite, GitHub Projects, Plane, Notion) without rewriting agents
- Atomic task claiming with SQLite WAL — zero race conditions
- Pull + Push dispatch with auto-fallback
- Multi-AI client support: Claude Code, TRAE, OpenCode, Codex, Qoder
- Rust + Tauri v2 desktop client (CLI + GUI)
- Docker deployment for Control Center

Whether you're a solo founder, indie developer, or small team, CeXia amplifies your capacity to that of a full cross-functional team.
