# 策匣 CeXia v1.0.0：用 AI Agent 团队运营你的虚拟一人公司

独立创始人面临的最大挑战不是想法不够，而是**时间不够**。产品规划、架构设计、开发、测试、运维、营销、行政 — 全部压在一个人身上。

策匣 CeXia 提供了一个全新的解决方案：**虚拟一人公司**运营模式。

## 核心理念

你 — 创始人 — 负责战略决策和优先级设定。一支由 9 个专业化 AI Agent 组成的团队 7×24 小时执行日常交付工作。

## 9 人标准团队

| 角色 | 职责 |
|------|------|
| 产品经理 | 撰写 PRD、管理待办列表、定义验收标准 |
| 架构师 | 设计系统架构、选择技术栈 |
| 全栈工程师 | 实现功能、修复 Bug（可并行多副本） |
| UI/UX 设计师 | 界面设计、文案、用户体验优化 |
| QA 工程师 | 自动化测试、Bug 报告、发布验证 |
| 运维工程师 | 数据分析、用户指标、运营诊断 |
| 市场营销 | 推广策划、内容生成、用户获取 |
| 行政与财务 | 报告生成、费用追踪、系统健康监控 |
| 巡检哨兵 | 工作流检查、过期锁清理、异常恢复 |

## 技术亮点

- **可插拔任务引擎**：通过配置切换后端（SQLite → GitHub Projects → Plane），无需重写 Agent
- **原子化认领**：SQLite 分布式锁，多 Agent 并行无冲突
- **双模调度**：WebSocket 推送 + REST 拉取自动降级
- **多 AI 客户端**：Claude Code、TRAE、OpenCode、Codex、Qoder
- **Rust + Tauri v2**：原生 macOS 桌面客户端
