🚀 Introducing CeXia v1.0.0 — the intelligent AI task collaboration platform that lets solo founders run like a full cross-functional team.

**What makes CeXia different?**

Unlike generic AI coding assistants, CeXia provides a complete team of 9 specialized agents with defined roles and responsibilities. Each agent communicates through structured task records — not free-form chat — eliminating ambiguity and race conditions.

**Technical highlights:**
- Pluggable abstract task engine: swap GitHub Projects → Plane → Notion via config, zero agent rewrites
- Atomic task claiming with SQLite WAL: multiple parallel agents never collide on the same work
- Pull + Push dispatch: REST Pull with WebSocket Push fallback
- Three-entity authentication: Admin JWT, Manager token, Instance token
- Rust + Tauri v2 desktop client with CLI + GUI
- Docker deployment for Control Center

**Who is this for?**
Solo founders, indie developers, and small teams who want to:
- Scale their output without hiring
- Automate repetitive development workflows
- Maintain clear audit trails of all agent actions
- Keep full control of their data and AI usage
