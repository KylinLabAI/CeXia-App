# CeXia v1.0.0 — Run Your Virtual One-Person Company

CeXia (策匣) is an intelligent AI task collaboration and scheduling platform that implements the "Virtual One-Person Company" operating model. The founder defines strategy; a team of 9 specialized AI agents handles execution 24/7.

## What's New in v1.0.0

- **9-agent standard team** with defined roles and responsibilities
- **Pluggable abstract task engine** with Built-In SQLite driver (default) + GitHub Projects V2 driver
- **Atomic task claiming** with SQLite lock database (WAL mode)
- **Standardized task lifecycle** from Backlog to Released
- **Pull + Push dispatch** with WebSocket push and REST pull fallback
- **Multi-AI client support**: Claude Code CLI, TRAE, OpenCode, Codex, Qoder
- **Three-entity authentication**: Admin JWT, Manager token, Instance token
- **Rust + Tauri v2** desktop client with CLI + GUI
- **Docker deployment** for Control Center

## Why CeXia?

As a solo founder, you need to handle product planning, architecture, development, QA, operations, marketing, and administration — all at once. CeXia amplifies your capacity by providing a team of AI agents that work in parallel, each with a specialized role and clear responsibilities.

The platform is designed for continuous improvement: better inputs (workflows, skills, tools, knowledge) = better AI performance over time.
